Activity 1: Planning the final (work with Gaozan Ye, Anzhe Huang)

I decided to work on the 2D final project because I am more familiar with 2D movement, physics, and kicking mechanics from previous minigames. My assigned section was the Player (Cat). I planned its Components, variables, and methods for movement, jumping, kicking, and animations, and I also did the connecting the different sections with arrows and labeling them to explain how the GameObjects interact with each other. 

Here is our drawing: [2D Final: Game System Plan](https://docs.google.com/drawings/d/1286u662xloXkmZQefktn-Hat1Bzrf9WbO-rhysgP6_E/edit)
